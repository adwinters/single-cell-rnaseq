# single-cell-rnaseq
Single-cell RNA-seq analysis workflows in R using Seurat, SoupX, SingleR, and related tools.

## Overview
This repository contains workflows for processing and analyzing 10x Genomics single-cell RNA-seq datasets. Analyses include ambient RNA correction, clustering, cell type annotation, visualization, and differential expression testing.

## Methods
- Cell Ranger data import
- SoupX ambient RNA correction
- Seurat preprocessing and clustering
- SingleR cell type annotation
- Differential expression analysis
- UMAP visualization

## Requirements
Key R packages used in these workflows include:

- Seurat
- SoupX
- SingleR
- celldex
- DoubletFinder
- harmony
- scran
- DropletUtils
- ggplot2

## Example Outputs
- Cell type distribution plots
- UMAP visualizations
- Cell type annotations
- Differentially expressed gene (DEG) tables
- Violin, feature, and box plots
